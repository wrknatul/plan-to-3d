# План → 3D

Демо: из плана квартиры в JSON строится 3D-сцена — стены с проёмами, расстановка мебели по правилам и проверка проходов. В браузере, без сборки, на Three.js.

**Открыть:** https://wrknatul.github.io/plan-to-3d/

## Что происходит

1. **Стены из контуров комнат.** Каждая комната — многоугольник с прямыми углами. Отрезки, общие для двух комнат, становятся внутренними стенами (10 см), остальные — наружными (25 см). В углах и Т-примыканиях стены стыкуются без щелей и двойных граней.
2. **Проёмы.** Двери и окна задаются точкой на стене и шириной; в стене вырезается проём, у окна — стекло и подоконник. Окно на внутренней стене, дверь мимо стены, пересекающиеся проёмы — ошибка с понятным текстом.
3. **Мебель по правилам.** Для каждого предмета перебираются позиции вдоль стен с шагом 5 см (обеденный стол — по сетке 10 см). Позиции, нарушающие жёсткие правила, отсеиваются, оставшиеся ранжируются по предпочтениям. Если обязательный предмет не встал, поиск возвращается назад и пробует следующие по качеству места для уже расставленных предметов.
4. **Проходы.** Поиск в ширину по сетке 2,5 см: от каждой двери должна быть возможность подойти к каждому предмету, не протискиваясь уже заданной ширины прохода.
5. **Объяснения.** Клик по предмету показывает, почему он стоит именно там и сколько позиций отсеяло каждое правило.
6. **Экспорт** сцены в `.glb`.

## Правила

Жёсткие (позиция отбрасывается):

| Правило | Пример |
| --- | --- |
| Предмет целиком в комнате, с учётом толщины стен | шкаф не «въезжает» в стену |
| Предметы не пересекаются | |
| Зона открывания двери свободна | квадрат со стороной в ширину двери |
| Окно не закрыто мебелью выше подоконника | шкаф и холодильник — не у окна, стол и диван — можно |
| Изголовье кровати не под окном | |
| Нельзя встать в зону подхода к другой мебели | перед шкафом остаются 80 см |
| Перед предметом может встать человек шириной прохода | раковина не в нише 60 см |
| Телевизор — напротив дивана | |

Мягкие (влияют на выбор): угол для шкафа и холодильника, гарнитур вплотную к холодильнику и мойка под окном, стол у окна, кровать по центру стены и подальше от двери, диван не на стене с дверью. Диван выбирается с заглядыванием вперёд: учитывается, где после него встанет телевизор.

## Формат плана

Координаты — в метрах по осям стен, `x` вправо, `y` вниз.

```json
{
  "name": "Пример",
  "height": 2.7,
  "rooms": [
    { "id": "living", "type": "living", "polygon": [[0, 0], [5, 0], [5, 4], [0, 4]] },
    { "id": "bath", "type": "bath", "items": ["shower", "sink", "toilet"], "polygon": [[5, 0], [7, 0], [7, 2], [5, 2]] }
  ],
  "doors": [{ "at": [5, 1], "width": 0.7 }, { "at": [2, 4], "width": 0.9 }],
  "windows": [{ "at": [2.5, 0], "width": 1.5, "sill": 0.85 }]
}
```

Типы комнат: `living`, `bedroom`, `study`, `kitchen`, `bath`, `hall`, `studio`. Набор мебели берётся из типа, его можно заменить полем `items`. Каталог с размерами — `src/catalog.js`.

## Устройство

```
src/geometry.js   плоская геометрия: многоугольники, прямоугольники, расстояния
src/plan.js       JSON → комнаты, стены, проёмы, внутренние контуры, зоны дверей и окон
src/layout.js     расстановка (перебор + правила + возврат) и проверка проходов (BFS)
src/catalog.js    мебель и типы комнат
src/scene.js      Three.js: пол, стены с проёмами, модели мебели, слой зон, подписи
src/main.js       интерфейс
test/             тесты на Node: правила соблюдаются на разных вариантах, ошибки входа, проходы
```

Логика (`geometry`, `plan`, `layout`) — чистые функции без Three.js, поэтому тестируется в Node и переносится на сервер без изменений.

```bash
python3 -m http.server 8765   # открыть http://localhost:8765
node --test                    # тесты
```

## Ограничения

- Только прямые углы: стены идут по осям.
- Правила — упрощённые эргономические нормы, не СНиП.
- Поиск ограничен по числу шагов, поэтому на очень тесных планах лучший вариант не гарантирован.
